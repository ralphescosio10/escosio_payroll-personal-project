## Database Backups

The application schedules a SQLite snapshot each day at 01:00 and automatically removes snapshots older than 30 days. Snapshots are written to `storage/app/private/backups`. This command supports file-backed SQLite databases; it will report an error for in-memory or non-SQLite databases.

Laravel's scheduler must be running for the daily backup to execute:

- On Windows, configure Task Scheduler to run `php artisan schedule:run` from the application directory every minute.
- On a server with cron, add `* * * * * cd /path/to/application && php artisan schedule:run >> /dev/null 2>&1`.

To restore a SQLite snapshot, stop the application and any queue workers, keep a copy of the current database file, then replace the configured SQLite database file with the chosen `.sqlite` snapshot. Ensure the restored file is owned and writable by the application account, then restart the application and verify payroll records. Do not restore over a live database.

Snapshots are stored on the same machine as the application and do not protect against disk loss or machine failure. Copy backups to a separate, access-controlled location regularly and test the restore process.

## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

Laravel's predictable structure and conventions make it ideal for AI coding agents like Claude Code, Cursor, and GitHub Copilot. Install [Laravel Boost](https://laravel.com/docs/ai) to supercharge your AI workflow:
